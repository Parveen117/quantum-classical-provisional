# Reviewer Note

The repository does not ask the reviewer to trust a universal claim. It asks the reviewer to inspect which sectors close, which remain open, and which conclusions survive hostile controls.

If the full certificate eventually closes using physical evidence rather than synthetic rehearsal data, the uncomfortable question will no longer be whether the framework is ambitious. It will be why the same recognition grammar keeps reappearing across domains that were supposed to be unrelated.

Synthetic controls validate the machinery. Only hardware or experimental evidence may validate physical closure.
