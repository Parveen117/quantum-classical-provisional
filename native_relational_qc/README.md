# Native Relational Quantum Calculator

An exact, bounded circuit calculator with rational coefficients, certified
outward decimal enclosures and explicit resource limits. The integrated tree
includes the flat field, full-register and record-conditioned phase estimation,
jet learner, active observer, and photonic model calculations. These are local
ideal-model computations; structured wide registers do not establish general
2056-qubit simulation or a quantum speed advantage.

## Install and run

Python 3.12 is tested in CI both with and without Qiskit; Python 3.11 is also supported.
The installed core depends only on NumPy.

```bash
python3.12 -m venv .venv
. .venv/bin/activate
pip install .                  # NumPy-only core
pip install '.[qiskit]'       # optional offline Qiskit adapters
nrqc check native_relational_qc/calculator_examples/bell.json
nrqc calculate native_relational_qc/calculator_examples/bell.json
nrqc certify --out certification.json
```

For development: `pip install -e '.[test]'` and `python -m pytest -q`.
Use `.[test,qiskit]` for adapter tests, `.[benchmark]` for Aer MPS and Stim,
and `.[cad]` for the optional layout checks. Current test results belong to
CI/test logs, rather than a manually maintained test count.

## Backend capabilities

Generated by `nrqc check --table`. `nrqc check INPUT.json` reports acceptance,
unsupported gate names, rejection reasons, and the resource caps for each backend.
Acceptance is static; it does not predict runtime resource growth. The calculator
requires an explicit backend and never silently substitutes one.

Every backend supports at most 32 queries per request. The flat backend admits
4096 scalar outputs per batch; the other backends admit 256. Common defaults
are 10,000,000 work units and 4096 coefficient bits; the respective ceilings
are 1,000,000,000 and 8192. The JSON input ceiling is 64 MiB. The phase backend
shares preparation and its work budget across the entire query batch. A
resource failure discards that whole batch; no truncated approximation is returned.

The flat backend's `max_branches` can be explicitly raised to 1,048,576. This
allows larger full-register 12-bit phase-estimation paths; support, work, wall
time and memory still bound feasible inputs. Defaults remain conservative.
The N=141, base 2, 12-bit full-register workload is
[qualified in two local runs](BENCHMARKS.md#full-register-12-bit-runtime-qualification)
at 160.1 s and 190.2 s under a 300 s deadline, with all 4,096 exact bins checked.
`readout_workers: 2` through `8` evaluates independent queries concurrently,
sharing immutable amplitudes and a synchronized batch work budget. Output order
is preserved. Threads may cost more than they save on small or Python-heavy
queries; they do not guarantee speedup. There is no hard total-RSS guard.

The retired `cyclotomic`, `cyclotomic32` and `cyclotomic64` Python modules are
compatibility views over `cyclotomic_pow2`, not separate product engines. They
retain historical constructors, coefficient bases and saved-ledger JSON. Their
backend names, gate alphabets and width limits remain valid. Photonic modules
import the canonical flat field directly. Sparse/dense products use exact
integer arithmetic, including an overflow-checked Python-integer fallback.

## Exact phases and interoperability

`pK`, `pKdg`, `cpK`, `cpKdg` use an exact power-of-two K up to 4096.
`compact_qiskit.to_qiskit` maps them to PhaseGate(±2π/K) or its controlled form;
`from_qiskit` accepts the same canonical numerical representation without a
rounding tolerance. Qiskit's floating-point angles alone do not prove symbolic
exactness. Use `openqasm.loads`/`dumps` to retain exact rational multiples of pi.

RZ import retains the scalar phase through an exact decomposition; it is never
silently substituted by P. Its half-angle must fit the same field cap, so RZ
requires a denominator at most 2048 in units of 2π. Non-dyadic, arbitrary decimal,
unbound and unsupported angles are rejected. See [phase transport](PHASE_INTEROP.md).

## Delta OGMT order-recognition test

The [retained Delta OGMT audit](DELTA_OGMT_ORDER_TEST.md) runs the proposed
ABAB/AABB task through the exact calculator with single-memory, parallel-memory,
double-triangle, edge-removal and reset controls. A separate 16-angle observer
scan retains every comparison, including where the full topology loses.
These are explicitly declared coherent circuit encodings, not calibrated
transistor or thermal models. Raw inputs/results and independent local Qiskit
checks are retained with hashes; no quantum hardware service is called.

## Ledger certification

`nrqc certify cluster` retains the collaborator’s separate corrected-path
cluster witness. See [cluster certificate](CERTIFY.md). `nrqc certify` (or
`nrqc certify ledger`) runs the four model-number checks below.

`nrqc certify` recomputes fusion success, environment-traced Bell weights, ideal
ZX purification and the classifier's source-noise bound. It returns exact values,
outward enclosures, source hashes and negative controls. `--claims claims.json`
checks supplied rational targets and returns a failing exit code on mismatch.
The 2.8w figure is rounded at one operating point: the exact first-order term
is (5/2)w plus the retained higher-order remainder. These results do not grant
laboratory qualification or promote conditional source sectors into supplied photons.
